# Java 后端学习 SKILL 使用说明

项目级技能，仅对 `JAVA_learn` 生效。计划仍是《Java 后端技术栈快速上手学习计划》，但支持**压缩时间、跳项、多日合并**。聊天是导读；真正的教材是 `dayN/学习笔记.md` + 配套可运行代码。

## 技能

| 技能 | 职责 |
|---|---|
| `java-learn-session` | 总控：识别标准 / 压缩 / 跳项 / 多日 |
| `java-learn-concept` | 按 7 节讲概念，并落盘 Demo |
| `java-learn-pair` | 写或评教学代码 |
| `java-learn-debug` | 分层排错；跳过则在笔记留故障清单 |
| `java-learn-review` | 收工 Review、定稿笔记、更新进度 |
| `java-learn-notes` | 笔记与学习包质量标准（每次写笔记都要遵守） |

自然语言即可；要强制指定时 `@` 技能名。

## 三种说法

**标准（分块，可答题）：**

```text
开始今天 Day 3 的学习。
```

**压缩（一次要齐笔记和代码）：**

```text
压缩学习 Day 2，直接介绍全部 OOP 概念，产出笔记和配套代码。
```

**跳项 / 多日：**

```text
今天合并 Day 3 和 Day 4，跳过排障和收工五问，把笔记和代码写到 day3、day4。
跳过 Day 5，从 Day 6 开始。
```

跳过某块时 Agent **不会再拦住你补做**，只会在笔记里标 `⏭`。

## 学习包长什么样

```text
dayN/
├── 学习笔记.md     # 离开对话也能看：概念、为什么、代码锚点、运行方式、自测、跳过记录
└── 配套源码        # 可编译；类名对准概念（如 ImportTask）
```

多日合并会分别写 `day3/`、`day4/`，不会揉成一个文件。

## 仍然有效的原则

- Java 17/21 + Maven；领域用 User / Task / Order
- 压缩时可以一次给齐材料，但笔记必须有「不用会怎样」和坑，不能只剩代码
- **配套代码必须带教学注释**：文件头标明 Day/概念，入口分段对齐计划条目，关键行写「为什么」（规范见 `java-learn-notes/code-comments.md`）
- 真实报错仍先分层再给补丁（你明确只要补丁时，根因会写进笔记）
